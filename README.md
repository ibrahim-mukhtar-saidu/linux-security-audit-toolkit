
# Linux Security Audit Toolkit

A beginner-friendly Linux security auditing toolkit that performs basic system security checks and helps identify common security issues on Linux systems.

## Features

* Checks current user privileges
* Displays running services
* Lists open network ports
* Shows active user accounts
* Displays recent login activity
* Checks password policy information
* Reviews SSH configuration status
* Reports basic firewall status

## Technologies

* Bash
* Linux command-line tools

## Example Usage

```bash
chmod +x audit.sh
./audit.sh
```
